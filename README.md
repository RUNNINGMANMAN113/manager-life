# MANAGER LIFE v0.9.26 — 코치·2군 감독 이벤트 논리성 점검 및 수정

v0.9.25의 사건 종류와 이미지, 기존 보직·승진 시스템을 유지하고 이벤트 발생 조건과 실제 선택 효과를 보강한 수정판입니다.

## 수정 사항

1. **상황 검증:** 재활 선수가 있어야 재활·복귀 이벤트가 발생합니다. 피로 관련 이벤트는 해당 포지션의 실제 피로 대상 선수에게 배정됩니다. 승리/연승/연패 이벤트는 퓨처스 실제 경기 결과를 확인하며, 시즌 후반/초반 이벤트는 기간을 제한합니다.
2. **대상 일치:** 포수·내야·외야·투수 관련 사건은 맞는 포지션을 우선 확인합니다. 스카우트는 실제 타 구단 선수를 대상으로 분석하며, 외부 선수의 능력치가 스카우트 업무로 직접 변경되지 않습니다. 전력분석원이 상대 선수를 분석할 때도 외부 대상을 찾습니다.
3. **선택 결과 연결:** 2군 선수를 주전으로 기용하면 실제 퓨처스 라인업에 등록해 출전할 수 있게 합니다. 보호 투수는 가용한 대체 투수가 있으면 선발에서 제외하며, 불가피한 출전 시 피로 누적을 낮춥니다. 3경기 로테이션에 부족한 선발은 2군 가용 투수가 임시 등판합니다. 집중 지도 선수가 3명이면 마지막 선수를 교체하여 새 선수를 지정합니다.
4. **후속 정보:** 2군 선수가 승격되면 그 사실을 2주 후 결과에 반영합니다. 코치 후속 평가가 이미 완료되었는데도 '3주 후 예정'으로 표시하는 오류를 수정했습니다. 담당 선수가 팀을 떠났다면 그 사실을 구분하며 스카우트 외부 대상 보고는 불필요한 이적·퇴단 문구를 사용하지 않습니다.
5. **서술과 장면:** 실제 경기나 우천 취소 기록이 없는데 이미 취소·승격되었다고 단정하는 텍스트를 준비·가능성 사건으로 수정했습니다. 승격 준비 사건은 실제 승격 완료 화면 대신 분석·상담 화면을 사용합니다.

## 검사한 항목

- JavaScript 포함 스크립트 39개 문법 검사 통과
- 코치 8개 직책 × 24주 진행: 직책당 사건 8개, 같은 시즌 내 중복 0개, JavaScript 실행 오류 0개
- 2군 감독 24주: 주간 3경기 × 24주 = 72경기, 현장 사건 7개 중복 없음, 시즌 종료 평가 완료
- 재활 선수 없는 투수코치 시즌의 거짓 복귀 사건 0건
- 스카우트 외부 구단 선수 선택 및 3주 후 관찰 보고 테스트 통과
- 2군 비주전 선수 출전 확대 → 다음 경기 명단 및 실제 3경기 출전 반영 검증
- 보호 투수 대체 선발 적용 검증
- 모바일 화면 390px 가로 넘침 및 이미지 로딩 검사 통과
- v0.9.25 상태 JSON을 v0.9.26으로 마이그레이션해 직책·주차·이벤트 이력이 유지되는 것을 검사

## 남은 문제 / 범위 한계

- 코치 커리어는 1군 정규시즌 경기 엔진과 모든 코치 사건이 1:1로 연결된 것은 아닙니다. 현재는 훈련·신뢰·선수 상태 중심의 반영입니다.
- 우천 사건은 다음 일정에 대한 대비 이벤트일 뿐, 실제 기상 데이터나 경기 취소를 생성하지 않습니다.
- 데모 로스터의 `DEMO-HIST` 과거 선수들이 2군 현역 선수로 등장할 수 있습니다. 이벤트 엔진과 별개로 선수 데이터·연도 유효성 검사가 필요합니다.
- 로컬 스토리지의 실제 브라우저 파일 간 저장·불러오기 테스트는 환경의 로컬/HTTP 파일 열기 제한으로 수행하지 못했습니다. 기존 상태 JSON 마이그레이션은 검증했습니다.
- 1군 시즌 전체, 감독 대행·국제대회·FA·타리그 이적·장기 저장에 대한 전수 회귀 테스트는 아직 완료되지 않았습니다.
