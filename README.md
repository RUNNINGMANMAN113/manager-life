# MANAGER LIFE v0.9.21

저장 복원 시 1군 및 감독 대행 배경 시즌의 일정과 순위표를 검사합니다.

코치·스태프 승진에 해당 시즌 감독 임무 수행 1건 이상을 반영합니다. 시즌 평가 점수와 등급을 통일하고 첫 면접 점수를 최대 100점으로 제한했습니다.

## GitHub 배포
1. 기존 저장 파일은 JSON으로 백업합니다.
2. 압축 파일 안의 `index.html`을 GitHub 저장소 루트의 `index.html`로 교체합니다.
3. GitHub Pages에서 실행합니다. 배포를 자동으로 수행하지는 않습니다.
